# Vuvio — Inspirations Strava & Polarsteps

## Objectif

Ce document rassemble les idées que Vuvio peut reprendre de **Strava** et **Polarsteps**, en les adaptant à son identité.

Vuvio ne doit devenir ni une application de sport, ni une application de voyage.

L’objectif est plutôt de combiner :

- **la spontanéité du live Vuvio** ;
- **la dimension communautaire et la valeur durable des activités de Strava** ;
- **la mémoire, le récit et l’exploration géographique de Polarsteps**.

> **Le live pour vivre l’instant.  
> Le globe pour découvrir le monde.  
> Les expériences pour conserver et partager ce qui a été vécu.**

---

# 1. Ce que Vuvio doit préserver

Le coeur de Vuvio reste :

- le live POV ;
- le monde réel ;
- les métiers ;
- les passions ;
- les activités ;
- les lieux ;
- les rencontres ;
- les événements ;
- la découverte à travers le regard d’une autre personne.

Vuvio doit pouvoir accueillir aussi bien :

- un boulanger ;
- un cycliste ;
- un artisan ;
- un guide ;
- un pêcheur ;
- un musicien ;
- un cuisinier ;
- un marin ;
- un voyageur ;
- un jardinier ;
- un photographe ;
- un professionnel de terrain.

Les inspirations Strava et Polarsteps doivent donc enrichir ce modèle, pas le remplacer.

---

# 2. Inspiration Strava — faire vivre un contenu après l’activité

L’idée la plus intéressante de Strava pour Vuvio n’est pas le tracking sportif.

C’est la manière dont une activité réelle devient :

1. un contenu ;
2. un élément du profil de son auteur ;
3. quelque chose que la communauté peut retrouver ;
4. une trace durable de ce qui a été vécu.

Pour Vuvio :

> **Un live ne devrait pas simplement disparaître lorsqu’il se termine.**

Chaque live peut devenir une **expérience**.

---

# 3. Une fiche d’expérience après chaque live

Après un live, Vuvio pourrait automatiquement créer une fiche d’expérience.

Exemple :

## Cycling through the Alps

- Alex
- Cycling
- Chamonix, France
- 1 h 42
- Replay disponible
- Highlights
- Équipement utilisé
- Date
- Réactions / commentaires
- Partage

La fiche pourrait contenir :

- miniature ;
- titre ;
- créateur ;
- catégorie ;
- lieu ;
- durée ;
- replay ;
- meilleurs moments ;
- équipement ;
- description ;
- statistiques pertinentes ;
- bouton de partage.

Le live devient ainsi un objet durable dans Vuvio.

Il peut ensuite apparaître :

- sur le profil du créateur ;
- dans Explore ;
- sur le globe ;
- dans une recherche ;
- dans une catégorie ;
- dans un partage externe.

### Priorité

**Haute.**

C’est probablement l’une des inspirations Strava les plus utiles immédiatement pour Vuvio.

---

# 4. Inspiration Strava — le profil comme collection d’expériences

Un profil Vuvio ne devrait pas seulement afficher :

- photo ;
- bio ;
- followers ;
- équipement.

Il pourrait progressivement devenir la **collection des expériences vécues par le créateur**.

Exemple :

## Alex

Explorer · Musician · Creator

### Experiences

- Cycling through the Alps
- Walking through Tokyo at night
- Rehearsal with my band
- Hiking in Patagonia
- Morning at a Paris bakery

Le profil raconte progressivement :

> **Voici le monde que cette personne nous fait découvrir.**

Cela donne une raison de suivre une personne au-delà d’un seul live.

### Priorité

**Haute.**

---

# 5. Inspiration Strava — communautés autour des activités

Strava montre l’intérêt d’organiser une communauté autour d’une pratique commune.

Vuvio peut reprendre cette logique de façon beaucoup plus large.

Exemples :

- Mountain Biking
- Life at Sea
- Craftsmanship
- Food & Cooking
- Street Photography
- Music
- Farming
- Surf
- Urban Exploration
- Aviation
- Fishing
- Hiking
- Local Guides

Une communauté pourrait regrouper :

- créateurs ;
- lives en cours ;
- upcoming lives ;
- expériences passées ;
- événements ;
- discussions plus tard.

### À éviter au début

Il n’est probablement pas nécessaire de créer immédiatement un système complet de clubs.

Les catégories et centres d’intérêt de Vuvio peuvent déjà remplir une grande partie de cette fonction.

### Priorité

**Moyenne / après lancement.**

---

# 6. Inspiration Strava — associer un parcours au replay

Pour certaines expériences mobiles, Vuvio pourrait associer la vidéo à un parcours géographique.

Exemple : un cycliste diffuse pendant 1 h 20.

Après le live, son expérience peut contenir :

- le parcours ;
- quelques moments importants ;
- la position correspondant à ces moments ;
- le replay.

Un utilisateur pourrait toucher un point sur le parcours et ouvrir le moment correspondant dans la vidéo.

Exemple :

- 00:00 — départ de Chamonix
- 32:18 — vue panoramique
- 1:06:40 — arrivée au sommet

Ce système est pertinent pour :

- randonnée ;
- vélo ;
- bateau ;
- voyage ;
- running ;
- visite de ville ;
- road trip.

Il l’est beaucoup moins pour :

- boulanger ;
- musicien ;
- artisan ;
- cuisinier.

Le produit doit donc rester contextuel.

### Vie privée

La localisation doit être :

- volontaire ;
- configurable ;
- éventuellement approximative ;
- désactivable.

### Priorité

**Plus tard.**

---

# 7. Inspiration Strava — challenges sans compétition excessive

Les challenges peuvent encourager certains types de contenus.

Mais Vuvio devrait éviter une culture trop centrée sur :

- les scores ;
- les classements ;
- la performance ;
- le nombre d’heures diffusées.

Les challenges devraient favoriser **l’exploration**.

Exemples :

## Sunrise Around the World
Partager des levers de soleil depuis plusieurs pays.

## A Day at Work
Faire découvrir son métier pendant une journée.

## Life at Sea
Partager des expériences de navigation ou de pêche.

## Behind the Craft
Montrer la fabrication d’un objet.

## One City, Many Perspectives
Faire découvrir une ville à travers plusieurs personnes.

### Priorité

**Plus tard.**

---

# 8. Inspiration Polarsteps — passer du live isolé à l’histoire

L’intérêt principal de Polarsteps pour Vuvio est différent de celui de Strava.

Polarsteps apporte surtout trois idées :

1. une expérience peut durer plusieurs jours ou plusieurs étapes ;
2. les expériences créent une mémoire ;
3. la carte permet de revisiter et raconter ce qui a été vécu.

Pour Vuvio, cela permet de passer :

> d’un live isolé

à :

> une histoire composée de plusieurs expériences.

---

# 9. Regrouper plusieurs lives en une aventure

Un créateur pourrait créer une **Adventure**, **Series** ou **Journey** regroupant plusieurs lives.

Exemple :

# Sailing across the Mediterranean

France → Italy

5 jours — 4 lives

### Day 1
Leaving Marseille

### Day 2
Life aboard the boat

### Day 3
Corsica

### Day 5
Arriving in Italy

Chaque étape correspond à un live Vuvio.

Cette logique peut aussi fonctionner hors voyage.

### Artisan

**Building a handmade guitar**

- choix du bois ;
- découpe ;
- assemblage ;
- finition ;
- premier essai.

### Musicien

**Recording an EP**

- répétition ;
- studio ;
- overdubs ;
- mix ;
- concert de lancement.

### Guide

**Discovering Tokyo**

- Shibuya ;
- marché ;
- quartier résidentiel ;
- vie nocturne.

### Priorité

**Moyenne**, après que les expériences individuelles soient solides.

---

# 10. Inspiration Polarsteps — créer une mémoire automatique

Vuvio ne devrait pas demander au créateur de refaire tout le travail après son live.

À partir de ce qui existe déjà, l’application peut conserver automatiquement :

- replay ;
- miniature ;
- date ;
- lieu ;
- activité ;
- durée ;
- équipement ;
- quelques moments forts.

Le créateur peut ensuite ajouter :

- titre ;
- petite description ;
- photos ;
- commentaires ;
- contexte.

Cela crée progressivement un **journal d’expériences**.

Mais il n’est probablement pas nécessaire de créer un nouvel onglet principal « Journal ».

Cette mémoire peut vivre directement dans :

- le profil ;
- les expériences ;
- les aventures.

---

# 11. Inspiration Polarsteps — suivre une aventure à venir

Une aventure peut exister **avant** qu’elle soit terminée.

Exemple :

# Sailing across the Mediterranean

### Upcoming

- Monday — Leaving Marseille
- Tuesday — Life aboard the boat
- Wednesday — Corsica
- Friday — Arrival in Italy

L’utilisateur peut :

- suivre l’aventure ;
- recevoir une notification ;
- revenir quand un nouveau live commence.

Cela crée une mécanique importante :

> **Donner une raison de revenir pour voir la suite.**

Aujourd’hui, un live est instantané.

Avec les aventures, Vuvio peut également créer de l’attente.

### Priorité

**Après la programmation des lives.**

---

# 12. Inspiration Polarsteps — le globe comme mémoire du monde

C’est probablement l’idée Polarsteps la plus forte pour Vuvio.

Aujourd’hui, le globe sert principalement à découvrir :

- ce qui est live ;
- ce qui arrive prochainement.

À terme, il pourrait également montrer les **expériences passées**.

On pourrait donc avoir trois états simples :

## Live
Ce qui se passe maintenant.

## Upcoming
Ce qui va bientôt commencer.

## Discover
Ce qui s’est déjà passé et peut être exploré.

Exemple : un utilisateur sélectionne Tokyo.

Il peut voir :

- un live actuel dans un marché ;
- une visite prévue le soir ;
- un replay d’un artisan ;
- une promenade nocturne ;
- une expérience culinaire passée.

Le globe devient alors :

> **une mémoire vivante des expériences humaines autour du monde.**

Cela résout aussi un problème important des plateformes de live au démarrage :

même lorsqu’il y a peu de lives simultanés, le globe reste riche grâce aux expériences passées.

### Priorité

**Moyenne à haute**, une fois les replays et expériences stabilisés.

---

# 13. Inspiration Polarsteps — le récapitulatif partageable

Après plusieurs lives appartenant à une même aventure, Vuvio pourrait produire un récapitulatif.

Exemple :

## 5 days sailing across the Mediterranean

- carte ;
- étapes ;
- meilleurs moments ;
- créateur ;
- durée totale ;
- lieux visités ;
- équipement ;
- lien vers l’aventure complète.

Un recap court pourrait être partageable sur :

- Instagram ;
- TikTok ;
- YouTube Shorts ;
- WhatsApp ;
- Messages ;
- lien web Vuvio.

Cela peut devenir une mécanique d’acquisition importante.

Le contenu publié ailleurs renvoie vers l’expérience complète dans Vuvio.

### Priorité

**Moyenne**, après stabilisation des highlights.

---

# 14. Ce que Strava apporte à Vuvio

Strava inspire surtout quatre principes.

### 1. La permanence
Une activité terminée garde de la valeur.

Pour Vuvio :

> un live terminé devient une expérience.

### 2. Le profil
Les activités construisent progressivement l’identité d’un utilisateur.

Pour Vuvio :

> les expériences racontent ce qu’un créateur fait découvrir.

### 3. La communauté
Les utilisateurs se retrouvent autour de centres d’intérêt communs.

Pour Vuvio :

> métiers, passions et activités peuvent devenir des univers de découverte.

### 4. Le lien activité / géographie
Certaines activités prennent plus de sens lorsqu’elles sont reliées à leur parcours.

Pour Vuvio :

> le replay peut être enrichi par la carte lorsque cela est pertinent.

---

# 15. Ce que Polarsteps apporte à Vuvio

Polarsteps inspire surtout quatre principes.

### 1. La narration
Plusieurs moments peuvent raconter une même histoire.

Pour Vuvio :

> plusieurs lives peuvent former une aventure.

### 2. La mémoire
Une expérience passée reste intéressante à revisiter.

Pour Vuvio :

> les lives deviennent une bibliothèque d’expériences.

### 3. La géographie
Les contenus prennent du sens lorsqu’ils sont replacés dans le monde.

Pour Vuvio :

> le globe devient à la fois temps réel et mémoire.

### 4. Le suivi
On peut suivre une histoire au fur et à mesure.

Pour Vuvio :

> un spectateur peut suivre une aventure et revenir pour son prochain live.

---

# 16. La combinaison Vuvio

## Vuvio aujourd’hui

```text
Créateur
   ↓
Live POV
   ↓
Spectateurs
```

## Vuvio enrichi

```text
Créateur
   ↓
Live POV
   ↓
Expérience
   ↓
Replay / Highlights / Equipment
   ↓
Profil du créateur
   ↓
Adventure / Series
   ↓
Globe / Explore / Discover
   ↓
Partage
   ↓
Nouveaux spectateurs
```

Le live reste le coeur du produit.

Tout ce qui vient ensuite permet simplement de prolonger sa valeur.

---

# 17. Architecture UX recommandée

Il faut éviter d’ajouter trop de nouveaux onglets.

La navigation principale peut rester simple :

```text
Watch — + — Globe — Profile
```

Les inspirations Strava et Polarsteps peuvent être intégrées à l’intérieur des surfaces existantes.

## Watch

- lives en cours ;
- recommandations ;
- accès rapide aux expériences.

## Globe

Filtres temporels :

- Live ;
- Upcoming ;
- Discover.

## Profile

Sections possibles :

- Experiences ;
- Upcoming ;
- Equipment ;
- About.

Plus tard :

- Adventures / Series.

## Replay

Le replay devient une vraie **Experience Page**.

Il peut contenir :

- vidéo ;
- highlights ;
- contexte ;
- lieu ;
- équipement ;
- carte si pertinente ;
- aventure associée ;
- partage.

---

# 18. Ce qu’il ne faut pas copier

## De Strava

Ne pas faire de Vuvio une application basée sur :

- performance ;
- vitesse ;
- distance ;
- records ;
- classements ;
- compétition permanente.

Ces éléments peuvent exister ponctuellement lorsqu’ils sont pertinents, mais ils ne doivent pas définir Vuvio.

## De Polarsteps

Ne pas faire de Vuvio une application uniquement centrée sur :

- voyage ;
- vacances ;
- road trips ;
- tracking GPS ;
- journal personnel.

Le système doit fonctionner aussi bien pour quelqu’un qui reste toute la journée dans son atelier.

---

# 19. Priorités recommandées

## Phase 1 — directement utile

### 1. Experience Page après un live
Transformer automatiquement le live terminé en expérience.

### 2. Experiences sur les profils
Construire progressivement l’historique du créateur.

### 3. Replay + highlights + equipment
Regrouper ces éléments dans la même expérience.

### 4. Partage propre d’une expérience
Créer un lien externe qui donne envie d’ouvrir Vuvio.

---

## Phase 2 — enrichir la découverte

### 5. Discover sur le globe
Afficher les expériences passées par lieu.

### 6. Upcoming plus visible
Permettre aux utilisateurs de suivre ce qui va se passer.

### 7. Regrouper plusieurs expériences
Créer Adventures / Series.

---

## Phase 3 — fonctionnalités avancées

### 8. Parcours GPS synchronisé au replay
Seulement pour les activités pertinentes.

### 9. Recap automatique d’une aventure
Highlights + carte + étapes.

### 10. Communautés et challenges
Créer des événements éditoriaux autour des catégories.

---

# 20. Exemple concret : expérience Vuvio complète

Imaginons une créatrice qui part travailler plusieurs jours sur un voilier.

## Avant

Elle crée :

**Atlantic Sailing — 4 days aboard**

Les utilisateurs voient les prochains lives.

Ils peuvent suivre l’aventure.

## Pendant

Chaque jour, elle démarre un live POV.

Les lives apparaissent :

- dans Watch ;
- sur le globe ;
- dans Explore ;
- dans son aventure.

## Après chaque live

Vuvio crée automatiquement :

- replay ;
- miniature ;
- highlights ;
- équipement ;
- lieu ;
- durée ;
- fiche d’expérience.

## Après quatre jours

La page Adventure contient :

- carte ;
- quatre expériences ;
- meilleurs moments ;
- équipement ;
- recap ;
- bouton de partage.

## Plusieurs mois après

Un nouvel utilisateur explore l’Atlantique sur le globe.

Il découvre cette aventure.

Il regarde un replay.

Il ouvre le profil de la créatrice.

Il la suit.

Lors de sa prochaine sortie :

> notification : **Alex is live on Vuvio.**

C’est là que Strava + Polarsteps deviennent particulièrement intéressants pour Vuvio :

**le contenu live éphémère devient une source durable de découverte et de fidélisation.**

---

# 21. Principe produit final

La combinaison à retenir est :

> **Vuvio = Live + Discovery + Memory**

### Live
Vivre quelque chose avec quelqu’un maintenant.

### Discovery
Trouver des personnes, activités et lieux intéressants dans le monde.

### Memory
Pouvoir retrouver, raconter et partager ce qui a été vécu.

---

# 22. Résumé en une phrase

> **Prendre à Strava la manière dont chaque activité enrichit durablement le profil et la communauté, prendre à Polarsteps la manière dont plusieurs moments deviennent une histoire et une mémoire géographique, puis appliquer ces principes aux lives POV de Vuvio.**

Le résultat ne doit pas être une copie de Strava ou Polarsteps.

Il doit renforcer ce qui rend Vuvio différent :

> **voir le monde à travers les yeux des autres, en Live — puis pouvoir continuer à l’explorer une fois le live terminé.**
