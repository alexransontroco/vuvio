VUVIO — Pitch Deck HTML / Paris&Co

OUVRIR
- Ouvrir index.html dans Chrome ou Safari.

REMPLACER LES IMAGES
- Tous les placeholders sont dans assets/placeholders/
- La méthode la plus simple est de remplacer une image en gardant exactement le même nom.
- Exemple : remplacez assets/placeholders/product-watch.png par votre vraie capture Watch.
- Vous pouvez aussi modifier le src directement dans index.html.

MODIFIER LE DESIGN
- css/styles.css contient les couleurs, grilles, espacements et tailles.
- Les variables principales se trouvent en haut du fichier.

MODIFIER LE TEXTE
- Le texte est directement dans index.html, dans chaque <section class="slide">.

EXPORTER EN PDF
- Ouvrir index.html dans Chrome.
- Imprimer > Enregistrer au format PDF.
- Marges : aucune.
- Arrière-plans graphiques : activés.
- Le CSS est configuré pour le format 16:9.
