## Convention éditoriale

- **Décidé** : orientation explicitement retenue, sans présumer de son implémentation.
- **Hypothèse** : conviction qui réclame une preuve.
- **À explorer** : solution possible, aucun engagement.
- **État technique** : seule la documentation d'audit ou le code récent peut le confirmer.
- Ne pas transformer une hypothèse de marché en statistique ou une idée future en feature disponible.
